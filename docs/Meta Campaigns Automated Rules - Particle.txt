Late Attribution Reactivator | #AO - Ad Level
This automated rule turns on paused ads with #AO in their name,
if they got conversions after being paused for the last 2 days and yesterday spend below 10$.

It gives another chance for assets that have already performed and maybe their performance tanked for a certain period.

Criteria:
        Ad Name Contains #AO
* AND Spend - Yesterday  < $10
* AND Purchases - Last 2 Days > 0
* AND Ad Status = Paused
* AND Adset Status = ACTIVE
* AND Campaign Status =  ACTIVE
* Every 15 minutes 24/7.

This automated rule increases the daily budget (+10%) if the Ad Set contains “#PGS” in their name & performs better than the Target CPA by overviewing both last 7 days & last 3 days performance.


Note:
When using daily budget increase rules we also need to set the Maximum daily budget cap.

* Adset Name Contains #PGS-FC
* AND Adset Status = ACTIVE
* AND Campaign Status =  ACTIVE

* AND Cost Per Purchase (Last 7 Days) < CPA (Condition)
* AND Cost Per Purchase (Last 3 Days) < CPA (Condition)
OR Cost Per Purchase (Last 3 Days) < CPA (Condition)
Every Day (Except Sunday) at 00:00 EST

Advanced Rules
Sunday's Stop Loss | Adset Deactivator | #SSL - ROAS Based
Pauses underperforming ad sets only after they’ve effectively spent at least 90% budget on Sunday only and ROAS is Below 1.00 .

+ If this rule is triggered it also adds “ | #SSL” at the end of the Adset Name.

Pauses Adset / Campaign — IF ALL RULES MATCH:
   * Adset Spend Today > 0.9 X Adset Current Daily Budget
   * AND Adset ROAS Today < 1
   * AND Adset Status = ACTIVE
   * AND Campaign Status =  ACTIVE
   * AND  Campaign Name doesn’t contain Winback
Every 15 Minutes only on Sundays.

Experimental Rules


Winners Booster 10% | #PGS - Adset Level
Boosts adsets daily budget by 10% of Current Daily Budget — IF ALL RULES MATCH:
   * Contribution Total >= Current Daily Budget X 1.2
   * AND Contribution Total <  Current Daily Budget X 1.4
   * AND Adset Name Contains #PGS
   * AND Adset Status = ACTIVE
   * AND Campaign Status =  ACTIVE
   * 20:00 every day (Except Sunday) | Rule range overview is set to today.

Contribution Total Breakdown:
      * ( Average Order Value - Cost Per Purchase) X Purchases


Examples:
      * Success Example — Increase by 10% of Current Daily Budget
      * Contribution Total = 620$
      * Current Daily Budget = 500$
Current Daily Budget = 500$ —> New Daily Budget = 550$

         * Logic
IF  Today’s Gross Profit Volume (By 20:00) > Current Daily Budget
THEN Increase Current Daily Budget by 10%+
